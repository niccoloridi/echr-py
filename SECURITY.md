# Security policy

## Supported versions

Security fixes are applied to the latest published `echr-py` release and to
the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability-reporting or Security Advisory interface for this
repository. If that interface is unavailable, contact the maintainer through
the address in the package metadata.

Include the affected version or commit, a minimal reproduction, the expected
impact, and any suggested mitigation. Credentials, private Court material, or
third-party personal data should not be included unless strictly necessary and
appropriately redacted.
